Cheap Text Monitors × Pretrained Representations

Headline: the value of pretrained features is regime-dependent —
in-distribution they do not help; when the dataset shifts, they do.

Three regimes, three curves: training size n · distribution shift · perturbation.

Jiayu Liao · Zeyu Pan · Yuhan Sun

0:00–0:15 · 开口第一句就是 headline（15 秒）

第一句必须直接给结论（Clarity 分），不铺垫、不念标题、不介绍组员。headline 念完停一拍，再用 n / shift / noise 三个词给路线图，翻页。

“The value of pretrained features is regime-dependent: in-distribution, they do not help — when the dataset shifts, they do. We show this on a cheap text monitor that judges math reasoning steps, as three curves: training size, distribution shift, and perturbation. First, every required element in sixty seconds — then the number behind the headline.”

The 60-second sprint — everything required, on purpose 1 / 2

  • Background. Verifying LLM reasoning step-by-step costs GPT-level calls or human labels — a cheap text-only monitor decides: is this step correct?
  • Problem setup. Δ(θ) = AUROC(pretrained) − AUROC(TF-IDF) over regimes θ = (train size n, distribution shift, perturbation). The only variable is where features come from.
  • Data. PRM800K (OpenAI, MIT license): 911,867 human-labeled steps, 27.9% incorrect; split grouped by problem — 632,422 train / 190,573 test.
  • Methods. Frozen MiniLM / bge-base / bge-large as feature extractors only; downstream = in-class logistic regression & linear SVM; baseline = word+char TF-IDF.
  • Metrics. Balanced accuracy / AUROC (never raw accuracy); 10 stratified seeds; grouped CV inside train; test touched once.

The result that “doesn’t look good” — Δ(n) in-domain

Δ AUROC (embedding − TF-IDF), full curve · 10 seeds, 95% band
paired Δ at n = 20…500, per-seed
  • Textbook expectation: pretrained features help most when n is small (sample efficiency).
  • Measured: n = 20 → everything ≈ 0.51, near random — nothing to compare. n ≥ 50 → Δ turns negative and stays monotone; 10/10 seeds same sign.
  • Full-data end: Δ = −0.045 … −0.064 (SVM), 95% CI excludes 0 — TF-IDF wins, significantly.

“Here is the honest curve. The textbook says pretrained features should shine at small n. At n equals twenty, everything is at chance — zero point five one — so there is no signal to harvest. From fifty on, the gap goes negative and never comes back; at full data, TF-IDF beats every embedding by five AUROC points or more, interval away from zero, ten seeds out of ten. This is not a failed experiment — it localizes where pretrained features do NOT pay.”

Autopsy: why the baseline wins — and why we trust it

Why TF-IDF wins here

  • One narrow domain: “therefore”, “=”, LaTeX fragments carry the signal — semantic-similarity embeddings smooth over exactly those tokens.
  • Step-level correctness is a narrow task: char n-grams are already a strong baseline. Embeddings pay exactly where word overlap stops working — across datasets (next slide).
  • 632k training steps is plenty for sparse features; “small data” is not this task’s bottleneck.
  • Embeddings were pretrained for meaning, not for correctness — objective mismatch.

How we made sure it’s real

  • Leakage check: first random split put steps of one problem in both sets → all metrics inflated; re-split grouped by problem.
  • Label bug: v1 kept only chosen completions → 99.8% positive; caught by degenerate metrics, fixed, everything re-run (all numbers today = v2).
  • 27.9% minority class → stratified seeds + balanced metrics; 50/50 re-check moves AUROC < 0.01.

左栏是"为什么数据不好看"的科学解释，右栏是"我们怎么处理"。bug 故事要坦然讲，这是诚实分。强调：两个"看着不对"的数字，一个是我们的错，一个是真发现。

“Why does the baseline win? This is one narrow domain — the signal lives in tokens like ‘therefore’ and equals signs, and similarity-trained embeddings blur exactly those. And with six hundred thousand steps, sparse features are not starving. Two numbers on the way here looked wrong. The first was our fault: our label construction kept only chosen completions — ninety-nine point eight percent positive. The metrics degenerated, we caught it, and re-ran everything. The second wrong-looking number — the negative gap — survived every check we could throw at it. So we report it.”

预演必问 “in-domain 为什么 TF-IDF 反而赢”：步级对错判断是窄任务，字符 n-gram 基线本来就很强；词向量的优势在词面重叠失效时（跨数据集）才体现——下一页就是证据。

The turn: change the regime θ, and the sign flips

E3 · MATH → GSM8K (composite shift, reported as such)
  • E3 shift: bge-large Δ = +0.020 [0.018, 0.021]; bge-base +0.006 [0.004, 0.008]; MiniLM n.s. — a clean size gradient.
  • Overfitting: train−test gap 0.153–0.168 (TF-IDF) vs 0.040–0.065 (embeddings) — ≈3× smaller.
  • E4 perturbation: both degrade ≤ 0.007 — honest parity, no robustness edge claimed.
  • E5 selective prediction: TF-IDF risk 0.271, marginally better — reported as-is.
Refined thesis: pretrained features are not most valuable when data is scarce —
they are most valuable when the distribution drifts.

“Now the ablations — this is where the story turns. Move the distribution from MATH to GSM8K and the sign flips: bge-large beats TF-IDF by plus zero point zero two zero, tight interval, and the gain grows with model size — a gradient, not a fluke. Why? The overfitting numbers: TF-IDF’s train-test gap is three times larger; in-domain it wins by memorizing, and memorization does not travel. Perturbations: parity, we claim nothing. Selective prediction: TF-IDF still slightly better, reported as-is. So the refined thesis: pretrained features are not most valuable when data is scarce — they are most valuable when the distribution drifts.”
